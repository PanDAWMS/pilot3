PanDA Pilot 3
=============

PanDA Pilot 3 is a dependency-free Python application that manages distributed
job execution on the ATLAS/PanDA computing grid. It runs on worker nodes,
fetches jobs from the PanDA server, stages input data, executes experiment
payloads, and stages output data back out.
